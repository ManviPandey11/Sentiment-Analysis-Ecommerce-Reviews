# Sentiment-Analysis-Ecommerce-Reviews

Sentiment Analysis of Women’s E-Commerce Clothing Reviews

Description:

This project analyzes customer reviews of women's clothing from an e-commerce platform to determine the sentiment (positive, neutral, or negative) expressed in the reviews.

Files in this repository:

SentimentAnalysis-EcommerceReviews.ipynb: Jupyter Notebook with the full code and analysis.

Womens-Ecommerce-Clothing-Reviews.csv: The dataset used for analysis.

Steps followed:

Data Loading and Exploration: Initial exploration of the dataset.

Data Preprocessing: Cleaning and preparing the data for analysis.

Sentiment Analysis: Using the TextBlob library to classify the sentiment.

Visualization: Visualizing the distribution of sentiments.

How to use this project:

Clone the repository: git clone https://github.com/your-username/Sentiment-Analysis-Ecommerce-Reviews.git

Install required libraries: pip install -r requirements.txt

Open and run the Jupyter Notebook.
